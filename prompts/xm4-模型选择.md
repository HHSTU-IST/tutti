# 模型选择

## 作业要求

使用 Jupyter Notebook (.ipynb) 文件进行探索性数据分析（EDA），获取如下信息和完成相应任务，二级列表每项均为10分

- 交叉验证
  - 对数据进行标准化
  - 进行5折交叉验证
  - 计算并打印交叉验证平均分
- 正则化
  - 计算 L1、L2 模型在测试集上的准确率
  - 打印 L1、L2 的准确率
- 混淆矩阵
  - 打印混淆矩阵
  - 计算 F1 分数
- AUC
  - 绘制ROC曲线
- 交叉熵
  - 计算不同正则化强度下L2正则化模型的交叉熵
  - 绘制上述数据折线图：正则化强度vs交叉熵

作业以 .ipynb 文件提交，文件命名模式为：`04-学号-姓名.ipynb`。
