# 支持向量机

## 作业要求

使用 Jupyter Notebook (.ipynb) 文件进行探索性数据分析（EDA），获取如下信息和完成相应任务，二级列表每项均为10分

- 线性可分SVM
  - 观察C参数对分类结果的影响
  - 绘制决策边界和间隔
- 核函数
  - 对比RBF核函数SVM与线性可分SVM的分类结果
  - 观察gamma参数对RBF核分类结果的影响
- 网格搜索
  - 使用网格搜索找出超参数组合
  - 将最佳核函数结果输出为透视表
- 不平衡数据
  - 使用自动类别权重处理不平衡数据，并用SVM建模，获取AUC值
  - 使用SMOTE过采样处理不平衡数据，并用SVM建模，获取AUC值
- 多分类策略
  - 使用OvR策略对数据集分类，输出训练时间和测试准确率
  - 使用OvO策略对数据集分类，输出训练时间和测试准确率
- 使用 `make_classification()` 构造数据集

作业以 .ipynb 文件提交，文件命名模式为：`05-学号-姓名.ipynb`。
