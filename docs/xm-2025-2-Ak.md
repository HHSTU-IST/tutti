## 四、计算题（每小题10分，共30分）

### 31. 基尼系数计算

设正例比例 $p_1=4/10=0.4$，反例比例 $p_2=6/10=0.6$。

则基尼系数为

$Gini(D)=1-p_1^2-p_2^2=1-0.4^2-0.6^2=1-0.16-0.36=0.48$。

### 32. 线性回归损失计算

当 x=1 时，预测值为 3，平方误差为 (3-2)^2 = 1。
当 x=2 时，预测值为 5，平方误差为 (5-5)^2 = 0。
当 x=3 时，预测值为 7，平方误差为 (7-6)^2 = 1。
因此 MSE = (1 + 0 + 1) / 3 = 2/3 ≈ 0.667。

### 33. 距离度量计算

欧氏距离 = sqrt((4-1)^2 + (6-2)^2) = sqrt(9+16) = 5。
曼哈顿距离 = |4-1| + |6-2| = 3 + 4 = 7。

## 五、简答题（每小题10分，共30分）

### 34. 简答题

【核函数作用】
核函数无需显式计算高维映射，直接在原空间计算内积，解决线性不可分问题。
【常用核函数】
1. 线性核：线性可分场景；
2. 多项式核：处理非线性关系；
3. 高斯核(RBF)：通用强非线性，最常用；
4. Sigmoid核：模拟神经网络。

### 35. 简答题

【基本假设】
1. 各属性在类别条件下相互独立；
2. 通过贝叶斯公式计算后验概率，选择概率最大的类别。
【优点】
1. 模型简单、训练和预测速度快；
2. 在文本分类等场景中效果稳定；
3. 对高维稀疏特征较友好。

### 36. 简答题

【核心区别】
1. KMeans 是划分式聚类，需提前指定 K 值，迭代优化；
2. AGNES 是层次聚类，自底向上合并，无需提前指定 K；
3. KMeans 计算速度快，适合大数据；AGNES 计算复杂度高；
4. KMeans 对初始质心敏感，AGNES 对噪声敏感；
5. KMeans 输出平面聚类，AGNES 输出层次树形结构。
