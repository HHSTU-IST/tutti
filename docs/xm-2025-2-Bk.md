## 四、计算题（每小题10分，共30分）

### 31. 线性回归梯度下降一步更新

初始预测值 $y^ = wx+b = 1\\times 2+0 = 2$。

误差项 $y^-y = 2-5 = -3$。

对 $w$ 的梯度：$\\partial L/\\partial w = (y^-y)x = (-3)\\times 2 = -6$。

对 $b$ 的梯度：$\\partial L/\\partial b = y^-y = -3$。

参数更新：

$w' = w - \\eta\\partial L/\\partial w = 1 - 0.1\\times(-6) = 1.6$

$b' = b - \\eta\\partial L/\\partial b = 0 - 0.1\\times(-3) = 0.3$

因此更新后 $w=1.6$，$b=0.3$。

### 32. 信息增益计算

H(D) = -(6/10)log2(6/10) - (4/10)log2(4/10) ≈ 0.971。
H(D1) = -(3/4)log2(3/4) - (1/4)log2(1/4) ≈ 0.811。
H(D2) = -(3/6)log2(3/6) - (3/6)log2(3/6) = 1。
H(D|A) = (4/10)×0.811 + (6/10)×1 = 0.9244。
g(D,A) = H(D) - H(D|A) = 0.971 - 0.9244 = 0.0466。

### 33. 朴素贝叶斯分类器

P(好瓜)=0.5
P(硬挺|好瓜)=0.4
P(清晰|好瓜)=1
P(坏瓜)=0.5
P(硬挺|坏瓜)=0.4
P(清晰|坏瓜)=0

P(好瓜|样本)=0.5×0.4×1=0.2
P(坏瓜|样本)=0.5×0.4×0=0

结论：测试样本是好瓜。

## 五、简答题（每小题10分，共30分）

### 34. 简答题

【关系说明】
1. 模型复杂度太低时，容易欠拟合，训练集和测试集表现都差；
2. 模型复杂度适中时，能够较好拟合数据并保持泛化能力；
3. 模型复杂度过高时，容易过拟合，训练集好、测试集差；
4. 常通过正则化、剪枝、早停、Dropout 等方式控制复杂度。

### 35. 简答题

【SVM 算法流程】
1. 核心目标：寻找能最大化两类样本间隔的最优分类超平面；
2. 构建带约束的优化问题，最小化结构风险，引入拉格朗日乘子；
3. 求解凸二次规划问题，得到支持向量与分类决策函数；
4. 线性不可分使用核函数映射到高维空间，转化为可分问题；
5. 对新样本代入决策函数，完成分类预测。

### 36. 简答题

【核函数作用】
核函数无需显式计算高维映射，直接在原空间计算内积，解决线性不可分问题。
【常用核函数】
1. 线性核：线性可分场景；
2. 多项式核：处理非线性关系；
3. 高斯核(RBF)：通用强非线性，最常用；
4. Sigmoid核：模拟神经网络。
