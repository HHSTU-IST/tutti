### 31. 信息增益计算

### 32. 距离度量计算

欧氏距离 $=sqrt{(4-1)^2+(6-2)^2}=sqrt{9+16}=5$。
曼哈顿距离 $=|4-1|+|6-2|=3+4=7$。

### 33. 线性回归损失计算

当 x=1 时，预测值为 3，平方误差为 (3-2)^2 = 1。
当 x=2 时，预测值为 5，平方误差为 (5-5)^2 = 0。
当 x=3 时，预测值为 7，平方误差为 (7-6)^2 = 1。
因此 MSE = (1 + 0 + 1) / 3 = 2/3 ≈ 0.667。

## 五、简答题（每小题10分，共30分）

### 34. 简答题

【SVM 算法流程】
1. 核心目标：寻找能最大化两类样本间隔的最优分类超平面；
2. 构建带约束的优化问题，最小化结构风险，引入拉格朗日乘子；
3. 求解凸二次规划问题，得到支持向量与分类决策函数；
4. 线性不可分使用核函数映射到高维空间，转化为可分问题；
5. 对新样本代入决策函数，完成分类预测。

### 35. 简答题

【AGNES 算法流程（自底向上）】
1. 初始化：将每个样本单独作为一个原始簇；
2. 计算所有簇之间的相似度（距离）；
3. 找到距离最近（最相似）的两个簇，将它们合并为一个新簇；
4. 重复步骤2、3，直到所有样本合并为一个簇或达到目标簇数；
5. 输出层次聚类树与最终簇结构。

### 36. 简答题

【核心思想】
1. 通过线性变换把原始数据投影到新的坐标轴上；
2. 新坐标轴按方差大小排序，优先保留方差大的方向；
3. 通过保留少数主成分达到降维目的；
4. 在尽量保留主要信息的同时减少特征维度。
